# Assignment #6 — jQuery

Student: Sultanali  
Group: SE-2529

A simple multi-page project for jQuery selectors, effects, DOM manipulation, and animations.

## Tasks

- Part 1: Setup and selectors (Tasks 0–1)
- Part 2: Visibility, fade, and slide effects (Tasks 2–4)
- Part 3: Lists, attributes, and forms (Tasks 5–7)
- Part 4: Animations (Tasks 8–10)
- Part 5: Accordion mini project (Task 11)

## How to run

1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser or using the Live Server extension.
3. Use the navigation bar to open each part.

An internet connection is required to load jQuery from its CDN.
